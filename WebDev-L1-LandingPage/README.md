## Project Overview

Nexora is a modern, responsive landing page created for a fictional digital solutions brand.

The project focuses on clean UI design, responsive layouts, visual hierarchy, reusable styling, and semantic HTML.

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* CSS Animations
* Responsive Media Queries
* Google Fonts

**JavaScript is not used**, keeping the project aligned with the Task 1 requirements.

## Features

* Sticky navigation bar
* Responsive mobile navigation
* Hero section
* Headline and subheadline
* Call-to-action buttons
* Features section
* About section
* Process section
* Statistics section
* Client testimonials
* Final call-to-action section
* Footer with contact information
* Social media placeholders
* Responsive desktop, tablet, and mobile layouts
* CSS-only animations and hover effects
* Consistent colour palette
* Accessible semantic HTML structure

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. The landing page will load immediately.

No server or JavaScript setup is required.
